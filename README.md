# Elviti Works website

A responsive, multi-page company website for Elviti Works.

## Pages
- Home
- About
- Services
- Projects & Portfolio
- Compliance & Credentials
- Contact / Request a Quote

## Stack
HTML, CSS and vanilla JavaScript. No build step or framework dependency is required.

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server.

## Before launch: client verification checklist
- Confirm the preferred public contact number and WhatsApp number.
- Confirm the current street address and whether it should be published.
- Confirm the final service list and which services are delivered directly or through partners.
- Supply approved project photographs, project descriptions and client permissions.
- Supply current company registration, tax, supplier, B-BBEE and safety documents where applicable.
- Confirm company history, leadership details and any approved testimonials.
- Connect the enquiry form to a proper CRM/email endpoint if a server-side lead record is required. The current form prepares a WhatsApp message and does not store submissions.

## Important content safeguards
The portfolio intentionally does not fabricate projects. The compliance page lists document categories only and does not claim that any specific certification or status is held. Replace these notes only with verified client-approved information.
